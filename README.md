# T-Lab — Bambu Lab P2S 向け AI 自動モデリングアプリ

「作りたいもの」を日本語で伝えると、AI が壁打ち形式で質問しながら仕様を詰め、
自動で 3D モデル（OpenSCAD → STL）を生成するアプリです。
生成した STL を Bambu Studio でスライスして Bambu Lab P2S で印刷します。

## できること

- 💬 **AIとの壁打ち**: 「玄関に鍵を掛けるフックが欲しい」のように曖昧に伝えると、AI が寸法・取付方法・用途などを質問して仕様を具体化
- 🧊 **自動モデリング**: 仕様が固まると AI が OpenSCAD コードを生成し、STL に自動変換。ブラウザ上で 3D プレビュー
- 🔁 **修正も対話で**: 「もう少し幅を広く」「角を丸く」と伝えるだけで新バージョン（v2, v3…）を生成
- 📋 **モデル管理**: 作りたいもの一覧を「相談中 → モデル生成済み → 印刷済み」のステータスで管理。過去バージョンの STL/SCAD もダウンロード可能
- ⚙ **モデルの使い分け**: 質問のやりとりは軽いモデル（Sonnet）、3Dモデルを作るときだけ高性能モデル（Opus）が担当。プランの利用枠の消費を抑えられます。画面左下の⚙から変更可能
- 🖨 **プリンタ状態表示**（任意）: P2S を LAN モードで接続すると印刷状態・温度・進捗を表示

## 必要なもの

| ソフト | 用途 | 入手先 |
|---|---|---|
| Python 3.11+ | アプリ本体 | https://www.python.org/ |
| OpenSCAD | AIが書いたコードを STL に変換 | https://openscad.org/downloads.html |
| Claude Code（Pro/Max サブスクで使う場合）| AI（Claude）との対話 | https://claude.com/claude-code |
| Bambu Studio | STL のスライスと印刷 | https://bambulab.com/ja/download/studio |

## セットアップ

### 1. 依存パッケージをインストール

```bash
pip install -r requirements.txt
```

### 2. AI の認証を設定（どちらか1つ）

**方法A: Claude Pro/Max サブスクリプションで使う【推奨・追加課金なし】**

Claude Agent SDK は Claude Code のログイン情報を使うため、サブスクの利用枠内で
このアプリを動かせます。

```bash
# Claude Code をインストール（未導入の場合）
npm install -g @anthropic-ai/claude-code

# 一度起動して Max プランのアカウントでログイン
claude   # ブラウザが開くのでログイン → 完了したら終了してよい
```

これだけです。`.env` の設定は不要です（`ANTHROPIC_API_KEY` を**設定しないこと**。
設定されていると API 従量課金が優先されます。本アプリはサブスクモード時に
子プロセスからキーを隠す防御はしていますが、設定しないのが確実です）。

**方法B: Anthropic API キーで使う（従量課金）**

```bash
cp .env.example .env
# .env に ANTHROPIC_API_KEY=sk-ant-... を記入
```

### 3. 起動

```bash
uvicorn app.main:app --reload
# → http://localhost:8000 をブラウザで開く
```

> **AIなしで試す**: `.env` で `MOCK_AI=1` を設定すると、AI の代わりに
> サンプル応答（壁掛けフック）が返り、モデリング〜プレビューの流れを確認できます。

### サブスク利用時の補足

- 利用量は Claude Code / claude.ai と共通の**プランの利用枠**（5時間ごとのウィンドウと
  週次上限）から消費されます。上限に達したら時間経過で回復します。
- 既定では**質問のやりとりを Sonnet、OpenSCAD の生成だけを Opus** が担当します
  （画面左下の⚙で変更可能）。往復の多い質問フェーズが軽いモデルになるため、
  1つのモデルで通すより利用枠の消費を抑えられます。
- さらに抑えたい場合は質問担当を Haiku に、モデリング担当を Sonnet にできます。
- 会話はプロジェクトごとに Claude Code のセッションとして継続され、2回目以降は
  差分だけ送信されるため効率的です。
- サーバーや CI などブラウザログインできない環境で動かす場合は、手元のPCで
  `claude setup-token` を実行して発行される長期トークンを、その環境の
  `CLAUDE_CODE_OAUTH_TOKEN` 環境変数に設定してください。

## 使い方

1. 「作りたいものは何ですか？」の欄に自由に入力（例:「スマホの卓上スタンド」）
2. AI の質問に答えて仕様を詰める（「おまかせ」と言えば AI が決めます）
3. モデルが生成されたら右パネルの 3D プレビューで確認
4. 形や寸法の修正があればそのままチャットで依頼 → 新バージョンが生成される
5. 「⬇ STLダウンロード」で STL を保存 → **Bambu Studio で開いてスライス → P2S へ送信して印刷**
6. 印刷したら「✅ 印刷済みにする」で管理ステータスを更新

## プリンタ連携（任意）

P2S 本体で **LANモード** と **開発者モード** を有効にすると、アプリ左下にプリンタの状態
（印刷中/待機、ノズル・ベッド温度、進捗%）を表示できます。

```bash
pip install bambulabs_api
```

`.env` に以下を設定:

```
BAMBU_IP=192.168.1.xx        # プリンタのIPアドレス（本体画面で確認）
BAMBU_ACCESS_CODE=12345678   # アクセスコード（本体画面で確認）
BAMBU_SERIAL=01S00A000000000 # シリアル番号
```

## スマホから使う（常時稼働サーバー構成）

> **ミニPCへの導入手順は [SETUP.md](SETUP.md) にチェックリスト形式でまとめてあります。**
> `./scripts/setup.sh`（環境構築）と `./scripts/install-service.sh`（常時起動化）で
> ほぼ自動でセットアップできます。

このアプリは PWA（ホーム画面に追加できる Web アプリ）として動くため、APK などの
ネイティブアプリを作る必要はありません。推奨構成:

```
[スマホ] ←Tailscale(無料VPN)→ [自宅のミニPC: 本アプリ常時稼働] ←LAN→ [Bambu Lab P2S]
```

1. **ミニPCにセットアップ**: 本アプリ + OpenSCAD + Claude Code（ログイン済み）+
   スライサー。GPU は不要です（AI はクラウド側で動き、OpenSCAD のSTL変換も
   スライスも CPU だけで数秒〜数十秒で終わります）
2. **常時起動**: `uvicorn app.main:app --host 0.0.0.0 --port 8000` を
   systemd などでサービス化
3. **Tailscale**: ミニPCとスマホの両方に [Tailscale](https://tailscale.com/) を
   インストールして同じアカウントでログイン。外出先からも
   `http://<ミニPCのTailscale名>:8000` でアクセスできます（ポート開放不要で安全）
4. **スマホのホーム画面に追加**: ブラウザでアプリを開き「ホーム画面に追加」。
   以降はアプリのように起動できます

### ワンタップ印刷まで自動化する

`.env` に `SLICER_CMD`（スライサーCLIのコマンド）とプリンタ設定（`BAMBU_*`）の両方を
設定すると、モデルプレビューに「🖨 P2Sで印刷開始」ボタンが現れ、
**スライス → プリンタへ送信 → 印刷開始** までワンタップで実行されます。

手順:

1. Bambu Studio（または OrcaSlicer）で P2S 用のプリンタ・印刷設定・フィラメント設定を
   作り、それぞれ JSON としてエクスポートして `profiles/` などに保存
2. `.env` に設定（例は OrcaSlicer。`{input}` と `{output}` は自動で実ファイルに置換）:

   ```
   SLICER_CMD=orca-slicer --load-settings "profiles/machine.json;profiles/process.json" --load-filaments profiles/filament.json --slice 0 --export-3mf {output} {input}
   ```
3. アプリを再起動して、モデル画面の「🖨 P2Sで印刷開始」を押す（確認ダイアログ付き）

> 印刷開始は物理的な動作を伴うため、必ず確認ダイアログを挟む設計にしています。
> フィラメントの残量とベッドの状態を確認してから実行してください。

## 仕組み

```
「壁掛けフックが欲しい」
        │
        ▼
┌─────────────────┐   質問と返答を繰り返して仕様を確定
│  Claude (AI)     │   （幅は？ 取付方法は？ 耐荷重は？）
└─────────────────┘
        │  OpenSCAD コード生成
        ▼
┌─────────────────┐
│  OpenSCAD CLI    │ → STL ファイル
└─────────────────┘
        │
        ▼
ブラウザで3Dプレビュー → STLダウンロード → Bambu Studio でスライス → P2S で印刷
```

- AI バックエンドは2系統: **claude-code**（Claude Agent SDK 経由でサブスクの利用枠を
  使用、既定）と **api**（`ANTHROPIC_API_KEY` による従量課金）。`.env` の `AI_BACKEND` で
  明示指定できます。
- api バックエンドのモデルは既定で `claude-opus-5`（`ANTHROPIC_MODEL` で変更可）。
  安全機構による応答拒否の際は `claude-opus-4-8` に自動フォールバックします。
- データは `data/` 以下に保存されます（SQLite + 生成ファイル）。Git 管理対象外です。
- 3D プレビュー用の three.js (MIT ライセンス) は `app/static/vendor/` に同梱しており、
  オフラインでも動作します。
